# B. D. Oboh Integrity Farm 🌱

A modern, responsive agricultural business website developed for **B. D. Oboh Integrity Farm**, an agricultural enterprise located in Oghara, Ethiope West LGA, Delta State, Nigeria.

The website provides visitors with information about the farm, its agricultural products, services, business location, contact details, and an online product enquiry/order interface.

---

## 🌾 About the Farm

**B. D. Oboh Integrity Farm** is an agricultural enterprise focused on farming, agricultural production, processing, and the supply of quality farm products.

## 🛒 Product Enquiry System

The website includes a product enquiry system that allows visitors to:

1. Browse available farm products
2. Select products
3. Specify quantities
4. Provide their name and phone number
5. Add additional notes
6. Send an order enquiry through WhatsApp or email

The system is designed as an **enquiry-based ordering system**, allowing the farm to confirm product availability, quantity, pricing, packaging, and delivery arrangements with customers.
